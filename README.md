## Task manager

Django-приложение для управления задачами.

Приложение задеплоено на render.com: _ссылка появится после деплоя_

### Локальный запуск

```bash
uv sync
cp .env.example .env
uv run python manage.py migrate
uv run python manage.py runserver
```
